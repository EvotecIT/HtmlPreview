# Roadmap

## Stage 1 - Static GitHub HTML Previewer

Implemented now.

- Static GitHub Pages app
- Public GitHub `.html` and `.htm` preview
- GitHub blob URL support
- Raw GitHub URL support
- Sandboxed iframe rendering

## Stage 2 - Better GitHub UX

Future only.

- GitHub repo file discovery
- Optional browser extension
- Context menu
- GitHub UI preview buttons
- Configurable preview domain

## Stage 3 - Controlled Gateway

Future only.

- `api.preview.evotec.xyz`
- Controlled asset fetching
- Caching
- Private repo support
- Token support
- Better MIME handling
- Larger and multi-file report support

## Stage 4 - Multi-forge / Product Integration

Future only.

- GitLab
- Bitbucket
- Gitea
- Codeberg
- Forgejo
- HtmlForgeX, TestimoX, DomainDetective, and ChartForgeX integration
- Report metadata
